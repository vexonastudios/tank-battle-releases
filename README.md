# Tank Battle LAN downloads

[Download the latest Windows installer](https://github.com/vexonastudios/tank-battle-releases/releases/latest)

Open the latest release and download **TankBattleLAN-Setup.exe**. This repository contains official installers and automatic-update files. Game source is maintained separately.

## Updating

Version 1.3.1 and later check this public channel automatically, verify downloaded updates, and install them when you exit the game unless automatic installation is disabled in Settings.

If you have version 1.2.2 or 1.3.0, install the current version once manually. Those versions check an old private update address and cannot discover the fix on their own.

All players in a multiplayer match should install the current version. Local-network play does not require an internet connection or GitHub account.

The `TankBattleLAN.exe` and `.sha256` assets are used by the automatic updater. Players only need the installer.
